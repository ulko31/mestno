## Социальные сети и отзывы

Массовый сбор Instagram и TikTok не выполнялся. Прямые попытки чтения выбранных страниц не дали доступного содержимого. Точный аккаунт «Питер Тусовка» нужно уточнить ссылкой, а не угадывать по названию. Поиск в открытом вебе не заменяет чтение закрытого поста или ролика. Официальный TikTok Display API работает с разрешением автора, Research API требует отдельного одобрения; доступа для этого проекта нет.

Форма **Моя база → Место из твоей подборки** принимает ссылку и собственную заметку. Сохранение происходит только в браузере; экспорт можно передать для редакционной проверки. `scripts/import_recommendations.py` разбирает этот экспорт в очередь `pending_review`. Он не загружает видео, не копирует подписи, не публикует непроверенные цены и фотографии. Для разрешённых текстовых экспортов есть `import_places.py --provider file` и `collect_reviews.py --input`.

Следующий полезный сбор: 5–10 конкретных подборок, затем проверка найденных заведений по меню, адресу филиала и актуальному расписанию. Несколько независимых отзывов могут подтвердить атмосферу, но один общий текст про заведение не доказывает открытый формат конкретной встречи.

Ранее реальный GitHub-импорт KudaGo вернул 403. OSM импортирован успешно. Новый адаптер событий KudaGo подготовлен и проверен на имитациях, успешная загрузка живой афиши не подтверждена. Сбой или отмена сохраняют прежний каталог.

[KudaGo API и условия](https://docs.kudago.com/api/), [OSM ODbL](https://www.openstreetmap.org/copyright), [TikTok Research FAQ](https://developers.tiktok.com/docs/en/research-api-faq), [TikTok Display API](https://developers.tiktok.com/doc/display-api-overview/).
