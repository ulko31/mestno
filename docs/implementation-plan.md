# Следующие этапы

## 1. Первый реальный импорт

Запустить кнопку KudaGo или готовый GitHub workflow. Проверить фактическое число пригодных карточек, координаты и список дублей. При успешном запуске передать экспорт для включения в общую опубликованную базу. Цель 500–1 500 кандидатов — план, а не уже собранные данные.

## 2. Сведения, которые отличают места

На первых 150–300 подходящих кандидатах проверить атмосферу и сценарии: панорама, растения, спокойный разговор, рабочая зона, музыка, открытые встречи, условия активности. Сверять актуальные комментарии через разрешённый API с официальной страницей и добровольными наблюдениями пользователей. Указывать источник, время/день, срок действия и противоречия. Тексты отзывов участвуют в подборе как мнения с датами, источниками и уточнениями. Очередь `pending_review` не становится подтверждёнными фактами без проверки.

«Неизвестное место» не определяется отсутствием рейтинга. Фильтр туристической классики — редакционный список. Дальше нужны личная история посещений и обратная связь, чтобы понимать, что ново для конкретного человека.

## 3. Общая серверная база

Развернуть хранение мест, источников, наблюдений и проверок по `data/schema.sql`. Клиент будет получать общую версию каталога. Обновления фактов и контекстных условий выполняются раздельно; импорт адреса не продлевает срок достоверности чужого отзыва. Начать с бесплатного уровня выбранного хостинга, проверив доступность API из его региона.

## 4. Более гибкий разбор запросов

Подключить языковую модель на сервере для извлечения намерения в ограниченный JSON: цели, настроение, компания, категории, обязательные/нежелательные признаки, бюджет, время и неизвестные условия. Детерминированный поиск проверяет ограничения в базе. Модель не создаёт места, цены и признаки из памяти. Ключ провайдера хранится только на сервере. Потребуются выбранный провайдер и небольшой лимит расходов.

## 5. Telegram и тестирование на знакомых

Для доступа из Telegram нужен общий HTTPS-адрес и настройка бота в BotFather. Сейчас публикация приватная. Перед изменением аудитории проверить экраны в обычном мобильном браузере и Telegram, сценарии API/ошибки/отмены и сохранение данных. Настройка Telegram не требует отправки токена бота в переписку.

## 6. Монетизация после проверки полезности

Оставить отдельные рекомендации бесплатными. Рассмотреть расширенные сохранённые планы, совместный выбор с друзьями и маршруты. Условия использования данных учитываются отдельно: платные функции приложения не должны превращаться в перепродажу материалов KudaGo.
