# Следующие этапы

## Уже выполнено

7438 карточек из редакционного снимка, OpenStreetMap и официальных площадок; 7349 с координатами, 139 с описаниями, 66 программ (65 актуальны на 13 октября), 24 места с бюджетом, 11 фотографий. Есть реальный сбор 37 публичных публикаций, 24 набережных, библиотечных встреч и отдельный кабинет локальных черновиков. Поиск читает тексты при запросе, показывает основания и варианты с уточнениями. Первая попытка KudaGo в GitHub вернула 403: реального корпуса отзывов пока нет. Получение разрешённых текстов — оставшийся блокер качества, а не необходимость проставить тысячи ручных признаков.

## 1. Корпус содержательных описаний и отзывов

Получить доступный разрешённый источник. KudaGo содержит документированные методы описаний и комментариев, но фактически недоступен из проверенной среды GitHub. Проверить кнопки импорта в браузере владелицы; при повторном 403 обратиться к поставщику или выбрать другой источник. Не обходить ограничения массовыми повторными запросами.

При успешном импорте тексты с датами и ссылками сразу участвуют в подборе. Тексты не равны подтверждённым фактам. Новая проверка комментариев не возвращает удалённые записи из старого кэша. OSM даёт адреса и координаты, но не отзывы.

## 2. Семантическая модель

Текущий анализ использует словарь, отрицания, временные условия и поиск по текстам. Для сложных формулировок подключить серверный разбор намерения и ранжирование найденных фрагментов. Модель получает только полученные документы; не придумывает места, цены и отзывы. Ключ — только на сервере. Понадобится выбранный провайдер и лимит расходов.

## 3. Общая серверная база

Развернуть хранение мест, источников и текстовых документов. Версии JSON уже дают всем посетителям общую опубликованную основу, но пользовательские дополнения пока сохраняются только в браузере. Не продлевать достоверность отзыва датой обновления адреса. Добавить синхронизацию и модерацию добровольных наблюдений.

## 4. Telegram и проверка продукта

Сохранён текущий приватный доступ. Для тестирования друзьями нужен доступный им HTTPS-адрес, согласованный отдельно. Проверить на телефоне и внутри Telegram, Код бота и Render Blueprint уже готовы; токен и живой запуск из этой сессии не подтверждены. Затем подключить серверную проверку initData для действий с личными данными. Оценивать конкретные запросы, открытия источников, сохранения и обратную связь после посещения.

Базовый подбор остаётся бесплатным. Расширенные функции монетизируются отдельно от перепродажи материалов внешних источников.
