# Загрузка мест и отзывов

Код проекта находится в [ulko31/mestno](https://github.com/ulko31/mestno). Сборщик получает описания, которые сразу участвуют в подборе. Комментарии добавляются как текстовые источники — без ручной разметки каждого места.

## GitHub без терминала

Первый импорт запускается после загрузки сборщиков в `main`. Повторить его можно так:

1. Открыть **Actions → Обновить каталог мест → Run workflow**.
2. Оставить город `spb`, 10 страниц и включённую загрузку отзывов.
3. Дождаться окончания. Зелёный результат означает успешное выполнение, но не гарантирует большое количество отзывов.
4. Скачать **Artifacts → mestno-catalogue-spb**.
5. Распаковать `places.json` и загрузить его в приложении: **Моя база → Загрузить файл каталога**.

В `places.json` находятся адреса, описания и тексты полученных отзывов с датами и источниками. В `review_candidates.json` — очередь проверки фактов и статистика реально загруженных отзывов. Неизвестные условия не превращаются в подтверждённые признаки.

Workflow не меняет ветку и не публикует сайт. При ошибке сохраняется `mestno-incomplete-result`; это промежуточные файлы, а не успешный полный импорт. Если API вернул 403 или 429, обходить блокировку сборщик не пытается. Текущий каталог сохраняется.

Другие города: `msk`, `ekb`, `kzn`, `nsk`, `nnv`. Они появляются в интерфейсе после загрузки своих записей.

## Из приложения

**Моя база → выбрать город → Загрузить места через API**. Получаются до 10 страниц по 100 записей, включая описания. Отзывы загружаются через GitHub или файл. Браузерный запрос зависит от доступности API и CORS; при сбое база сохраняется. Ключ не требуется, геопозиция не передаётся.

## Через Python

```bash
python3 scripts/import_places.py --provider kudago --city spb --max-pages 10
python3 scripts/collect_reviews.py --max-places 50 --max-pages 2
```

Оба шага обновляют `dist/places.json`. Второй добавляет `documents` типа `review`, не изменяя подтверждённые признаки. Сначала нужны места с реальными `provider_ids.kudago`.

Для локальных разрешённых экспортов:

```bash
python3 scripts/import_places.py --provider file --input catalogue.json
python3 scripts/collect_reviews.py --input comments.json
```

Формат комментариев: `{"kudago:123": {"results": [{"id": 1, "date_posted": 1791633600, "text": "…", "is_deleted": false, "reply_to": null}]}}`.

OSM как дополнительный источник фактов:

```bash
python3 scripts/import_places.py --provider osm
```

Стандартный прямоугольник OSM относится к Петербургу. Для другого города нужны свои границы. Снимок OSM не содержит отзывов.

## Как читаются отзывы

Официальный метод: `GET /public-api/v1.4/places/{id}/comments/`. До 50 мест выбираются с разнообразием форматов, до двух страниц на место. Сохраняются до 12 различных текстов на место за последние два года. Удалённые сообщения, ответы, дубликаты и будущие даты не включаются. Имена, аватары и профили не запрашиваются. Контактные данные в тексте удаляются.

Отзывы старше 180 дней могут быть только историческим вариантом с уточнением. Отрицания, конфликтующие мнения и временные условия видны при подборе. Отзыв не доказывает актуальную цену, бесплатность и доступность услуги. Для подтверждённых фактов используется отдельная очередь `pending_review`.

Описание с датой получения не означает повторную проверку заведением всех условий. Приложение показывает основания и оставшиеся вопросы. Парсер запросов пока не является языковой моделью.

## Данные для поиска

Карточка может не иметь ни одного `feature`. Достаточно текстовых документов:

```json
{
  "documents": [{
    "id": "description:123",
    "kind": "description",
    "text": "Описание из разрешённого источника",
    "source_url": "https://example.org/place/123",
    "observed_at": "2026-10-11T12:00:00Z",
    "retrieved_at": "2026-10-11T12:00:00Z"
  }]
}
```

Для отзыва `kind` — `review`, `observed_at` — дата публикации. Для временной выставки задаются `valid_from` и `valid_until`. Каждому источнику нужна собственная ссылка; файлы объединяются по ID либо точному названию, адресу и городу. Филиалы не склеиваются только по названию.

[KudaGo: поля и лицензия](https://docs.kudago.com/api/), [OSM: ODbL](https://www.openstreetmap.org/copyright). Социальные сети и Яндекс/Google не подключены к массовому копированию отзывов. Другие источники добавляются отдельными адаптерами после проверки доступного способа получения и прав использования.
