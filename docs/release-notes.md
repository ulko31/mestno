# v0.6 — бюджет, расширенная афиша и кабинет админа

- Средний чек учитывается как бюджет на человека. Подходящие неизвестные цены показаны по умолчанию с предупреждением; есть фильтр только известных сумм. Подтверждённое превышение бюджета исключается.
- Реально собраны 34 датированные библиотечные программы у 11 площадок; добавлены творческие группы и бесплатная рабочая зона. Всего 66 программ, из них 65 актуальны на 13 октября. Детские занятия не подменяют знакомства взрослых.
- 19 мест имеют опубликованный бюджет; цена кофе, депозит и цена за двоих не заменяют полную стоимость участия одного человека.
- 11 настоящих фотографий включены в сайт вместе с авторами, лицензиями и подписями.
- Создан отдельный кабинет для мест, бюджетов, программ и фотографий. Черновики сохраняются в браузере и участвуют в местном подборе; общая публикация через GitHub пока отдельная. Публичный сервер Telegram не выдаёт редактор.
- Импорт и добровольная форма социальной ссылки перенесены из поиска в кабинет. Владелице не нужно вручную заполнять все места.
- Полный успешный сбор библиотечной афиши снимает отменённые и исчезнувшие программы, дополнение фото не возвращает старые события.

Покрытие: 7402 адреса, 90 с описаниями, 7324 с координатами, отзывов посетителей 0. Массовый сбор Instagram/TikTok и языковая модель не подключены. Визуальная проверка на телефоне и доставка сообщений в живом Telegram ещё нужны.

# v0.5 — занятия, цены и Telegram-бот

- Убран большой зелёный текст над выдачей.
- Добавлены 21 предложение от организаторов: общие мастер-классы, книжные и разговорные клубы, настолки, танцы, импровизация и готовка. Частные группы не проходят поиск знакомств. В карточке доступны другие программы.
- У 10 мест есть цены с источниками: средний чек, пример заказа, стоп-чек или стоимость занятия. Неизвестная цена скрыта при бюджете, включается отдельным переключателем. Напиток не заменяет цену активности.
- Даты и записи показаны отдельно; регулярная программа не обещает занятие сегодня. Подготовлен API-импорт событий, успешного живого импорта пока нет.
- Три настоящие фотографии CC BY-SA 4.0 с автором, оригиналом и подписью. Остальные обложки остаются графическими.
- Геолокация использует разовую точку: места без координат не попадают в радиус. Импорт сохраняет в браузере только дополнения, включая закрытия.
- Telegram-бот использует тот же поиск и открывает нужную карточку. Webhook, ошибки и повторная доставка проверены имитациями. Живой запуск требует токена BotFather; инструкция и Render Blueprint готовы.
- Добавлены собственные рекомендации по ссылкам из соцсетей и экспорт очереди проверки. Instagram и TikTok автоматически не собирались.

Покрытие v0.5: 7387 карточек, 75 с описаниями, 7313 с координатами; отзывов посетителей 0. Проверка на телефоне и в реальном Telegram ещё впереди.

# v0.4 — поиск по текстам

- Исправлена пустая выдача из-за неизвестных цен и недостающих признаков атмосферы.
- Описания и загруженные отзывы читаются при запросе, без обязательной ручной разметки.
- Сохраняются отрицания, противоречия, даты и временные условия. Есть основания со ссылками.
- Появились варианты с явным списком условий для уточнения; проверенные превышения бюджета исключаются.
- Конфликт категории в тексте и фильтре объясняется. Повторить запрос без фильтров можно, сохранив его текст.
- KudaGo импортирует описания. Комментарии попадают в documents каталога, отдельно от подтверждённых features.
- Первый импорт OpenStreetMap выполнен: 7377 карточек, 7313 с координатами. Данные сохранены в приложении и репозитории.
- KudaGo в GitHub вернул 403: корпус отзывов остаётся пустым, без подмены адресами. Есть браузерная загрузка отзывов к импортированным карточкам KudaGo.
- Большой встроенный каталог не копируется в localStorage: сохраняются пользовательские дополнения.

Платная языковая модель, общая серверная база и серверная проверка Telegram initData пока не подключены. Наличие готового сборщика не означает успешного сетевого импорта; количество полученных документов проверяется по результату запуска.
