# Кабинет админа

[Открыть редактор Местно](https://city-context-spb.wintry-moss-6546.chatgpt.site/admin.html). Доступ защищён текущим приватным сайтом для владелицы. В публичном сервере для Telegram страницы `admin.html` и `admin.mjs` не выдаются.

Это первая версия редактора: изменения сохраняются в браузере и участвуют в подборе на этом же сайте. Другой телефон, браузер и сервер бота пока используют опубликованный каталог. Общей серверной базы, аккаунтов администраторов и автоматической публикации черновиков ещё нет.

1. Найти место по названию или адресу и открыть его слева.
2. Изменить описание, бюджет на человека, источник, координаты, программы или фотографии. Пустой бюджет означает неизвестную цену; 0 — подтверждённую бесплатность. Средний чек, пример заказа, час и стоп-чек сохраняют свой смысл.
3. Сохранить черновик и открыть карточку для проверки. Новые запросы в этом браузере учитывают изменения; открытая вкладка поиска получает их через событие хранилища.
4. Чтобы включить правки в общую версию, нажать «Скачать каталог для публикации» и передать файл для проверки и обновления GitHub. «Скачать черновик» сохраняет только изменённые карточки. Перед очисткой черновиков стоит скачать нужные изменения.

Для программы указаны формат общей/частной группы, дата и время Москвы либо регулярное расписание, возрастная аудитория, условия участия и ссылка записи. Детские занятия не подменяют знакомства взрослых. Неизменённые цены сохраняют старую дату проверки и другие тарифы.

Для фото нужны автор, страница оригинала, лицензия либо разрешение и подпись. Публичность изображения сама по себе не означает разрешение использовать его в приложении.

Форма «Место из твоей подборки» добровольная: сохраняет ссылку и собственное описание в очередь проверки, не публикует автоматически и не разбирает ролик. Владелице не нужно вручную заполнять весь каталог: первоначальный сбор и проверку данных выполняем со стороны разработки.

API и импорт файлов также находятся здесь, отдельно от обычного поиска. Крупный стартовый каталог не копируется в localStorage; сохраняются импортированные дополнения и изменённые карточки. При нехватке места редактор сообщает об ошибке и предлагает экспорт.
