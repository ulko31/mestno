# Telegram-бот Местно

Код готов; живой запуск отложен по решению владелицы до доработки качества поиска. Токен BotFather разработчику не предоставлен. Если бот уже настроен, повторная регистрация не нужна. Все сетевые вызовы в тестах заменены имитацией; отправки реальным пользователям не было.

Бот принимает свободный запрос, использует тот же `dist/search.mjs`, что и Mini App, и возвращает до трёх мест. Для занятия показывает формат, время, цену и запись. Кнопка **«Открыть карточку»** передаёт ID места и выбранного события в Mini App; приложение открывает эту карточку поверх поиска. При бюджете подходящие варианты с неизвестной ценой также показываются с предупреждением, что соответствие сумме не подтверждено.

Команды: `/start`, `/help`, `/app`, `/nearby`, `/forget`. Поиск рядом использует разовую точку и радиус 5 км. Запрос и координаты остаются в памяти сервера не более 10 минут; `/forget` удаляет их. Переписки и геопозиции не записываются в логи или репозиторий. Групповые чаты и живые трансляции геопозиции не обрабатываются.

## Что нужно сделать владелице

1. Открыть [@BotFather](https://t.me/BotFather), отправить `/newbot`, задать название и свободный username, заканчивающийся на `bot`. Сохранить полученный токен.
2. Открыть [настройку Render из этого репозитория](https://dashboard.render.com/blueprint/new?repo=https%3A%2F%2Fgithub.com%2Fulko31%2Fmestno). В репозитории уже есть `render.yaml`. Выбрать свой workspace и бесплатный план `Free`. Ввести токен **только в поле BOT_TOKEN в Render**, а не в GitHub, исходники или чат. `WEBHOOK_SECRET` сгенерируется автоматически.
3. После зелёного deploy открыть свой бот и проверить `/start`. Сервер настроит webhook, команды и кнопку Mini App автоматически. Открытый адрес Render будет обслуживать приложение для Telegram. Это отдельная публикация: существующая версия в ChatGPT остаётся приватной.

Render Blueprint создаёт доступный из интернета сервис и копию Mini App. Если нужен закрытый первый тест, после создания сервиса добавь переменную `BOT_ALLOWED_USER_IDS` со своим числовым Telegram ID; это ограничит ответы бота. Сам сайт Render при таком варианте остаётся публичным. Для закрытой веб-версии потребуется отдельная авторизация — поле списка ID не ограничивает сайт.

Проверка сервера: `https://<имя-сервиса>.onrender.com/healthz`. `bot_configured: false` означает, что приложение работает, но токен не подключён. `true` означает наличие настроек, а не подтверждение доставки сообщения. Окончательная проверка — `/start` и реальный запрос в Telegram. В логах успешной настройки будет только username, без токена.

Если у токена уже настроен другой webhook, код останавливает перенастройку: проверь, что это токен нового бота. Не меняй webhook работающего другого проекта.

## Работа бесплатно и ограничения

Сторонних Node-библиотек и платной языковой модели нет. Бесплатный Render может засыпать после 15 минут без входящих запросов и просыпаться около минуты: первое сообщение после простоя может прийти с задержкой. Доступность 24/7 на этом плане не обещается. [Официальные ограничения Free](https://render.com/docs/free).

Каталог — версионированный файл из GitHub. Импорт, избранное и посещённые из браузера пока не синхронизируются в бота. Поиск в боте начинает с Петербурга; города из Mini App можно добавлять позднее отдельной настройкой. Контекст и защита от повторных обновлений хранятся в памяти, после перезапуска сбрасываются. Свободные места в группах проверяет организатор по ссылке записи.

## Локально для разработчика

Скопировать `.env.example` в `.env`, заполнить реальные значения локально. `.env` исключён из Git. Node 22+:

```bash
node --env-file=.env bot/server.mjs
```

Для webhook нужны доступный HTTPS `WEBHOOK_ORIGIN`, `MINI_APP_URL` и `WEBHOOK_SECRET`. После запуска сервера:

```bash
node --env-file=.env bot/setup.mjs
```

Не вставляй токен в URL браузера или в командную строку. Не запускай токеном другого действующего бота. `SERVE_MINI_APP=false` по умолчанию не открывает статические файлы; `true` включает их на этом сервере.

[Telegram Bot API](https://core.telegram.org/bots/api), [BotFather](https://core.telegram.org/bots/features#botfather), [Render Web Services](https://render.com/docs/web-services).

Кабинет админа доступен в приватной версии ChatGPT; публичный сервер не выдаёт страницы редактора. Его черновики не меняют файл каталога сервера. [Как подготовить изменения к публикации](admin.md).
