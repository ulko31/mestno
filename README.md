# Местно — найди своё место

Telegram Mini App для поиска мест под планы, настроение и компанию. Интерфейс поддерживает загруженные города. Стартовый снимок: 65 мест Санкт-Петербурга, 15 категорий и 49 ссылок на источники. Туристическая классика скрыта по умолчанию.

## Изменения поиска

Поиск читает описания и импортированные отзывы во время запроса. Отсутствие заранее проставленного признака не исключает место, если в тексте есть подходящее основание. Работа с ноутбуком ищется в кафе, библиотеках и других форматах. Дополнительные слова ищутся в самих текстах с нормализацией словоформ.

Есть две группы: подходящие места с описанными условиями и варианты, где нужно уточнить цену, время или отдельное условие. Неизвестная цена больше не даёт пустую выдачу. Проверенная цена выше бюджета, закрытие, запрет ноутбуков и явно неподходящее расстояние исключают карточку. Бесплатный вход не доказывает бесплатность игры или рабочего места.

Рядом с объяснением показаны дата, короткий фрагмент и ссылка на источник. Противоречивые, условные и старые отзывы не становятся проверенными фактами. Категория кафе не доказывает атмосферу для мечтаний. Утренние условия не применяются к вечеру; временная выставка учитывается только в её даты.

**Это локальный анализ текстов по правилам и поиску слов, а не подключённая языковая модель.** Произвольная сложная формулировка может потребовать уточнения. Неучтённые слова показываются пользователю. Платных ключей нет.

## Запуск

Любой статический HTTP-сервер должен обслуживать `dist/`. Сборки и сторонних библиотек нет; открытие через `file://` не загрузит каталог JSON. Telegram требует доступный HTTPS-адрес. Текущий сайт остаётся приватным для владелицы.

[Как загрузить места и отзывы](docs/api-setup.md).

## Импорт

KudaGo: названия, адреса, координаты, описания и отдельно комментарии по документированному API. Тексты хранятся в `documents` карточек со ссылками и датами. Имена, профили, аватары и фотографии авторов не запрашиваются. Контактные данные в комментарии удаляются. Отзывы сохраняются отдельно от подтверждённых `features`.

Workflow «Обновить каталог мест» запускается при изменении сборщиков в `main` и вручную. Первый запуск получает до 1000 записей и отзывы максимум к 50 местам разных форматов. Результат — скачиваемый `places.json`; workflow не коммитит данные и не публикует сайт. Количество фактически полученных записей видно в логах и экспорте. Нет гарантии, что у каждого места существуют свежие отзывы.

Стартовый снимок содержит редакционные заметки, а не массовый корпус отзывов. До успешного импорта нельзя считать базу отзывов заполненной. API из среды разработки ранее вернул 403, Overpass — 504; сетевой результат GitHub проверяется отдельно.

## Структура

- `dist/search.mjs`: разбор запроса, ограничения, ранжирование и варианты с уточнениями.
- `dist/text-analysis.mjs`: поиск по текстам, отрицания, даты, контекст и объяснения.
- `dist/providers.mjs`: браузерный импорт описаний и объединение каталогов.
- `scripts/import_places.py`: импорт KudaGo, OSM или локального экспорта.
- `scripts/collect_reviews.py`: тексты комментариев → `documents`; отдельно очередь проверки признаков.
- `.github/workflows/refresh-catalogue.yml`: получение и экспорт каталога.
- `tests/`: проверки запросов, событий интерфейса, текстов и импорта.
- `data/schema.sql`: проект будущей серверной базы, ещё не развёрнут.

## Проверка

```bash
node --test tests/*.test.mjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

Сценарий со скриншота — ноутбук, кафе, спокойная атмосфера и до 1000 ₽ — покрыт тестом: подходящие рабочие кафе остаются в вариантах с уточнением неизвестной цены. Проверяется и поиск кафе по описанию без единого признака `laptop_work`. Проверка в браузере, на телефоне и внутри Telegram ещё не выполнена.

## Ограничения

Импорт, избранное и посещённые места сохраняются в этом браузере; серверной синхронизации ещё нет. В стартовых 65 карточках отсутствуют координаты и большинство цен. Время дороги, открытие сейчас, свободный стол и места на событии не проверяются. Геопозиция не отправляется поставщикам каталогов.

[KudaGo: документация и условия](https://docs.kudago.com/api/), [OSM: ODbL и атрибуция](https://www.openstreetmap.org/copyright). У каждого материала сохраняется прямая ссылка. Чужие фото не используются. Базовый подбор бесплатный; перепродажа материалов источника не предусмотрена.
